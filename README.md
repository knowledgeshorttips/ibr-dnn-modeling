# ibr-dnn-modeling
Deep Neural Network Modeling of Inverter-Based Resources for High-Fidelity Power System Dynamics
Title: Code and data for "Deep Neural Network Modeling of Inverter-Based Resources for High-Fidelity Power System Dynamics"

Description:
Simulation code, dataset and trained models supporting the article "Deep Neural Network Modeling of Inverter-Based Resources for High-Fidelity Power System Dynamics". The study compares a conventional 15-state reduced-order model, a hybrid model in which a deep neural network replaces the current limiter of the reduced-order model, and direct neural-network surrogates, against a detailed 23-state model of a 500 kVA grid-forming converter connected to a synchronous generator and a load through a 415 V / 11 kV transformer. Scenarios are generated by Latin-hypercube sampling of six inputs (converter share, load, load step, inertia constants, fault severity). All data are simulated; no field data are used.

Contents: ibr_dnn_pipeline.py (full pipeline, Python/SciPy/PyTorch), ibr_dataset.npz (289 simulated cases), ibr_models.pt (trained networks), CSV and JSON result files, README.md, requirements.txt.
